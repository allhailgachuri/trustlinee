# Trustline Insight — Developer Guidelines

## Repository Structure & Architecture
- **Framework**: React 19 + TypeScript + Vite Client SPA
- **Routing**: `@tanstack/react-router`
- **Data & State**: `@tanstack/react-query` + Mock In-Memory API Layer
- **Styling**: Tailwind CSS v4 + Semantic Financial Risk Design Tokens
- **Charts & Visualizations**: Recharts + Framer Motion
- **Icons**: Lucide React

## Development Workflow
- Run local dev server: `npm run dev`
- Build production SPA: `npm run build`
- Preview production bundle: `npm run preview`
